Methodology

K-Means Clustering is an unsupervised learning algorithm that groups data points into $K$ distinct clusters based on their feature similarity (Euclidean distance).

The Elbow Method plots the WCSS (Within-Cluster Sum of Squares) against different values of $K$. The "elbow" point is where the rate of drop slows down significantly, marking the optimal cluster count.

Scaled Space Analysis

Features are standardized to a standard normal distribution (mean=0, variance=1) prior to clustering to ensure that units do not skew distance calculations.
